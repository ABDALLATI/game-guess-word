# 🎮 Word Guessing Game

A simple and interactive word guessing game built with HTML, CSS, and JavaScript. Players have limited attempts to guess the hidden word, with helpful hints and keyboard navigation.

## 🚀 Live Demo
  https://abdallati.github.io/game-guess-word/
## ✨ Features
- 🎯 Guess the hidden word with limited attempts
- 💡 Helpful hints along the way
- ⌨️ Keyboard navigation support
- 📱 Clean and responsive design
- 🔄 Replayable — play again anytime

## 🛠️ Built With
- **HTML5** — Semantic structure
- **CSS3** — Modern styling and responsive layout
- **Vanilla JavaScript** — Game logic and DOM manipulation

## 🧠 What I Learned
- Handling keyboard events
- Managing game state with JavaScript
- DOM manipulation and dynamic UI updates
- Conditional logic and validation
